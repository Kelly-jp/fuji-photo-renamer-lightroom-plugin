# C2PA / Content Credentials（JUMBF）

## 対応範囲

オプションは既定 OFF です。ON の場合、今回書き出した JPEG に埋め込まれた JUMBF を除去します。資格情報・来歴を失う操作であることを UI に表示します。再署名、外部マニフェスト、全形式の C2PA 除去、透かしの除去は対象外です。

ExifTool 公式資料は、対応する JPEG などの JUMBF グループを `-jumbf:all=` で削除できると説明しています。これはコマンドの機能根拠であり、Lightroom 出力の安全性検証や選択的な C2PA のみの削除を保証するものではありません。JUMBF 全体の除去で他の JUMBF データも失う可能性を説明します。[ExifTool Jpeg2000 / JUMBF タグ資料](https://exiftool.org/TagNames/Jpeg2000.html)

## 対象ファイルの制限

- 元 RAW、元 JPG、XMP、カタログ元画像を削除コマンドへ渡さない。
- レンダリング済み一時ファイルから新規作業コピーを作り、セッション ID、生成経路、所有パスを記録する。
- 正規化したパス文字列だけで判断しない。リンク解決や実体同一性を確認し、元画像と同一なら拒否する。
- ユーザー指定の任意パス、ディレクトリ、ワイルドカード、再帰処理を受け付けない。
- 作業コピーへの限定書き込みと、未確定出力の清掃も同じ所有チェックを通す。

実体同一性を SDK / OS で十分に検証できなければ処理を拒否します。SDK の一時レンダリングであるとの根拠なしに「書き出しファイル」とみなしません。

## 処理と検証

1. 作業コピーの JPEG 形式と所有を検証し、元画像群の参照と区別する。
2. JUMBF、EXIF、XMP、ICC、画像構造の検証用スナップショットを取得する。
3. 所有済みの単一作業コピーにだけ JUMBF 削除を実行する。
4. 終了コード、警告、再読取結果を確認する。JPEG のデコード、画像データ・ピクセル不変性、対象外メタデータ保持を検証する。
5. JUMBF が残る、読み取れない、対象外情報が壊れた場合は失敗として確定保存しない。
6. 成功時だけ衝突を避けて出力先へ保存する。

以下は複製した検証用ファイルだけで使うコマンド例です。以下は初期検討の例です。現行の実装は Phase 10 の -o による新規出力方式を参照してください。

```sh
exiftool -jumbf:all -G3 -b -j -u -struct staged-export.jpg
exiftool -jumbf:all= staged-export.jpg
```

通常生成されるバックアップも専用作業領域に置き、プラグイン所有を記録します。元画像を書き換えるオプションやフォルダ一括削除は使いません。JUMBF 不在は成功の無変更処理として扱いますが、読取失敗を「不在」と解釈しません。

## 検証ゲート

[技術検証 5](testing.md#技術検証項目) で JUMBF あり / なし / 破損、ICC あり、EXIF / XMP あり、複数 JPEG 構造を調べます。ExifTool だけの再読取に加え、独立した JPEG 構造確認や C2PA 検証ツールを選定します。元画像群のハッシュ不変を確認します。削除 ON の失敗を黙って OFF 相当で続行しません。

## Phase 8 の設定 UI

削除設定をチェックボックスとプリセット対象へ追加しました。既定 OFF。削除処理は Phase 10 のため、ON の値は保存・復元しますが書き出しは理由を表示して拒否します。元画像への削除コマンドは追加していません。[UI の手動確認](phase8-export-dialog.md)

## Phase 9 の統合状態

C2PA OFF の JPEG 保存だけを接続しました。ON は削除未実装のため書き出しを拒否します。書き出しファイルの C2PA / JUMBF は変更せず、元画像群への削除命令も追加しません。削除の作業コピーと所有追跡は Phase 10 の責務です。

## Phase 10 の実装

ExifToolの `-o <専用作業フォルダー>/cleaned.jpg -jumbf:all=` で処理済みの新規コピーを作ります。`-overwrite_original`は使わず、元RAW/JPG/XMP・SDKレンダリング入力もExifToolからは変更しません。SDK由来を確認したハンドル、source内容と参照先、JPEG非JUMBF領域の全バイト比較、削除後JSONを確認し、成功したコピーだけを保存します。入力不変と実JPEGの画素一致を確認済みですが、今回のLightroom実機経路は未確認です。[仕様・制約・手動ゲート](phase10-c2pa.md)
