# 要件

## 状態と対象

2026-10-08 時点の設計仕様です。Phase 1 の最小 SDK プラグインを実装済みで、macOS の基本保存と元 RAW / XMP の内容不変についてユーザー報告があります。全体の技術検証は未完了です。Phase 2 の ExifTool 単体読取を追加しました。書き出しとの全体統合は未実装です。以下の「必須」は製品要件、「初期設計」は検証結果で調整できる実装方針を示します。

対象は Adobe Lightroom Classic のみ、Lua / Classic SDK、Windows / macOS。最低対応バージョン、CPU 構成、Lua バージョンは公式 SDK 確認後に決定します。ExifTool は配布物へ同梱します。クラウド版 Lightroom、動画、Publish Service、外部アップロードは対象外です。

## 機能要件

| ID | 必須の動作 |
| --- | --- |
| F-01 | Export Service Provider として書き出し画面に独自設定 UI を追加する。登録方法とフックは SDK で確認する。 |
| F-02 | ファイル名テンプレートを設定でき、未知トークン・不正構文を実行前に表示する。 |
| F-03 | 実行時と同じ解決・整形規則でプレビューを表示する。未確定の連番・衝突名はその旨を示す。 |
| F-04 | ExifTool で XMP / RAW / JPG を読み取り、項目単位で XMP → RAW → JPG の順にフォールバックする。 |
| F-05 | RAW 探索場所を「JPG と同階層」「JPG の 1 つ上」「同階層 → 1 つ上」から選択できる。RAF / DNG を最低限サポートする。 |
| F-06 | Date、Time、DateTime、Original、CameraMaker、Camera、LensMaker、Lens、FilmSim、ISO、FocalLength、Sequence、Extension の 13 トークンを扱う。 |
| F-07 | メーカー重複省略を切り替えられる。比較は正規化後に行い、同一ならカメラメーカー側を残す。 |
| F-08 | C2PA / Content Credentials（JUMBF）削除を選択できる。削除対象は今回生成した書き出しファイルだけに制限する。 |
| F-09 | 指定出力フォルダへ生成名で保存し、衝突は別名化する。暗黙の上書きをしない。 |
| F-10 | エラー、キャンセル、処理件数を報告する。失敗した写真を成功扱いしない。 |

## 初期設計

- 最初の統合検証は JPEG 出力。他形式は保存・削除処理を検証するまで対応を約束しない。
- RAW 探索の初期値は「同階層 → 1 つ上」、メーカー重複省略は ON、C2PA 削除は OFF。
- テンプレート初期値は `{DateTime}_{Original}_{Sequence}.{Extension}`。
- ファイル名だけをテンプレートで指定し、出力フォルダは別設定とする。
- 入力・設定を書き出し開始時に固定し、1 枚ずつ処理する。並列化、常駐 ExifTool、永続キャッシュは初期範囲に含めない。
- 詳細は [メタデータ](metadata-resolution.md)、[トークン](tokens.md)、[C2PA](c2pa.md) を正とする。

## 安全要件

| ID | 不変条件 |
| --- | --- |
| S-01 | 元 RAW、元 JPG、XMP、Lightroom カタログ内の元画像の内容を一切変更しない。 |
| S-02 | 既存の出力ファイルを暗黙に上書きしない。保存時点でも衝突を検出する。 |
| S-03 | 書き込み・削除・清掃はセッションで所有を記録した作業ファイルに限定する。元画像と同じ実体なら拒否する。 |
| S-04 | C2PA 削除は新規レンダリングから作った作業用コピーのみで行い、成功確認後に出力を確定する。 |
| S-05 | ExifTool 引数へユーザー文字列を無検証で連結しない。任意オプションやコード実行を許可しない。 |
| S-06 | 存在しない SDK API を推測しない。公式リファレンス・サンプルで根拠を確認する。 |

## 非機能要件と受け入れ条件

core は SDK、ExifTool、I/O なしで単体テストできる。外部処理にタイムアウトを設け、破損 JSON、非ゼロ終了、警告、権限不足を明示する。ログに写真の全メタデータや個人情報を既定で保存しない。

受け入れには、[テスト計画](testing.md) の技術検証 1〜6、安全性テスト、Windows / macOS の実機確認が必要です。各項目の証拠、使用バージョン、未対応条件を記録するまで、実現可能・対応済みと記載しません。

## Phase 1 の限定範囲

ユーザーの段階的実装指示に従い、SDK のみで JPEG を一時レンダリングし、標準の「書き出し場所」で選んだ保存先へ `test_<元ファイル名>.jpg` としてコピーします。特定フォルダー、元画像と同じフォルダー、標準フォルダー、後で選択、サブフォルダーに対応します。ExifTool、RAW / XMP 探索、テンプレート、C2PA は実装しません。F-09 の衝突時別名化は Phase 7 まで保留し、Phase 1 は同名時にエラーにすることで S-02 を維持します。ユーザーの保存先拡張指示に基づき、明示的に指定したサブフォルダーはレンダリング成功後に作成します。サブフォルダー名は単一の名前とし、親への移動・絶対パス・区切り文字・予約名は拒否します。カタログへの追加・スタック追加は検証版の対象外です。

出力に利用しにくい元ファイル名は置換せず拒否します。元画像不在時も拒否します。製品版の規則を変更するものではありません。実装・検証状態は [Phase 1 記録](phase1-lightroom.md) を参照してください。

## Phase 2 の限定範囲

ユーザーの次フェーズ指示に基づき ExifTool ラッパーと単体診断メニューを追加します。読み取り専用、明示したツールによる検証、既定同梱パスの解決、固定タグ・JSON・内部項目変換、実行時間制限に限定します。Phase 1 の Windows 等の未確認事項は継続します。F-04 の項目単位マージ、F-02 / F-03 のテンプレート・プレビュー、F-08 の削除機能は実装しません。[Phase 2 記録](phase2-exiftool.md)
