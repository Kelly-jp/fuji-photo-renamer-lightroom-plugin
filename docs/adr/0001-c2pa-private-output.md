# ADR 0001：C2PA削除は新規の作業出力だけに適用する

- 日付：2026-10-10
- 状態：採用（実機の対応判定は継続）

元RAW/JPG/XMPを変更しない要件と、前回設定の書き出しでSDK生成JPEGが通常フォルダーへ残る経路を両立する必要があります。

SDKのrendition型・生成先・元写真パスを照合した不透明なハンドルを発行します。ExifToolはこのハンドルだけを受け付け、`-o <専用作業フォルダー>/cleaned.jpg -jumbf:all=`で新規ファイルを生成します。`-overwrite_original`は使いません。公式仕様上、`-o`と同オプションの併用は入力削除につながるためです。

削除後のExifTool再読取と、独立したJPEG構造・対象外バイト列比較が成功したコピーだけを保存します。元のSDK生成JPEGは参照先と内容を再確認してから取り除き、二重出力を防ぎます。元写真や不明なファイルは削除しません。

検証を簡潔かつ有限にするため、JPEGは64 MiBまで、JUMBFは通常の32ビット長APP11パケットに限定します。未対応・破損・警告・停止未確認は失敗です。停止未確認の作業フォルダーは保持します。Windows、競合、リンクの実機検証は別途必要です。
