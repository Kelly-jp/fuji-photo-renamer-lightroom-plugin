# ADR 0002：OS別ExifToolとmacOS用Perlの同梱

## 背景

ユーザーにExifTool / Perlの追加インストールを求めず、固定バージョン・公式ハッシュ・第三者通知を伴うZIPが必要です。macOS用pkgやシステムPerlだけを利用する方式は自己完結要件を満たしません。

## 決定

ExifTool 13.59を固定します。Windows x64は公式ZIPの実行ファイルと`exiftool_files`をセットで保持し、実行ファイル名だけを変更します。macOSは公式Perl配布のスクリプト・libと、公式Perl 5.44.0をソースからビルドしたApple Silicon用ランタイムを同梱します。Intel Macはユーザーの指示により対象外です。Perlの再配置可能@INCと静的libperlを使い、外部のPerl環境設定を解除するランチャーから起動します。

バイナリはGitへ含めません。固定URL/SHA-256を検証してキャッシュへ準備し、全準備済みファイルを再検証した後、必要なプラグインファイルと対象OSの依存だけをZIPへ入れます。ライセンス本文・依存通知・ソース入手先・ビルド手順・ファイルハッシュを保持します。既存キャッシュやZIPの暗黙の置換は行いません。

## 理由と制約

未検証の第三者macOSバイナリやHomebrewのインストール先をコピーする方式より、公式ソースとビルド手順を固定できます。5.42.0候補から現行安定版5.44.0へ変更し、残るDarwinのCODESET問題には公式ソースで指定された`HAS_BROKEN_LANGINFO_CODESET`を適用します。機能全体や失敗テストを除外して合格扱いにはしません。

開発側にはCLTとビルド時間が必要です。Windows公式依存のPerl 5.32.1、署名・公証・隔離属性・クリーン環境にはリリース前の確認が残ります。取得のハッシュ固定とZIP生成だけで対応・安全性を保証しません。[実行方法・根拠・検証](../phase12-packaging.md)

## 2026-10-23：ad-hoc署名

ユーザーがDeveloper IDを持たず、Gatekeeperの制約を当面受け入れる方針を明示したため、macOSのパッケージ組立コピーへad-hoc署名を付けます。Mach-Oヘッダーからネイティブコードを検出し、モジュールごとに署名・検証してからPerl本体を署名します。`--deep`による一括署名は使いません。Lua、スクリプト、ライセンス、Windowsバイナリは署名対象外です。準備キャッシュを保持し、署名後にmanifestとZIPのハッシュを計算します。OSの信頼設定や隔離属性は変更せず、Developer ID・公証は引き続き対象外です。
